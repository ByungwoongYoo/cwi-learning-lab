# 실제 증거와 주장 범위

| 항목 | 확인된 범위 | 입증하지 않은 것 |
|---|---|---|
| Stage 1 | 고정 JSON 모델 CPU 추론, 로컬 HTTP 업로드·추론, 41 pytest 테스트와 별도 65 AI 점검 | 브라우저 UI 검증, 배포, 탐지 성능 향상 |
| Stage 2 | 145-파라미터 CPU PyTorch 학습과 같은 런타임의 128 = 37 + 91 업데이트 재개 일치 | 유용한 뼈 탐지, 일반화, 대규모 학습 |
| 데이터 | 공개 TRAIN 이미지 쌍 2개, 하나의 Chicken1 필렛 | 독립된 생물학적 표본 2개, 새 held-out 검증 |
| 구현 역할 | AI_ASSISTED | 사용자 단독 작성·독립 숙련·개인 경력 인증 |

Stage 1의 41 테스트와 65 별도 AI 점검은 중복될 수 있으므로 106개 독립 테스트라고 합산하지 않습니다. CPU 실습과 일반 웹 UI는 CUDA, WebGL 또는 실제 다중노드 실행 경험을 입증하지 않습니다. Stage 2의 표본은 양성 1개/음성 8191개이며 최종 예측은 전부 음성입니다. 낮은 훈련 손실은 성공적인 탐지를 뜻하지 않습니다.

결과와 정확한 근거 파일은 저장소 루트의 [EVIDENCE.md](../../../EVIDENCE.md)를 참조하세요.
