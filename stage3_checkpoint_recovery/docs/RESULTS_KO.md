# 결과와 주장 범위

## 실제 실행

2026-10-26, 최초 frozen_probe: **19.900초**, 최초24 unittest PASS.

선택 순서의 명시적 assertion과 디렉터리 열거 수 제한을 보강한 최종 소스에서 **final_probe 19.536초**, 최종24 unittest **PASS**. 최초/최종 결과를 서로 다른 실험 구성의 성능 비교로 해석하지 않는다.

순서는 다음과 같습니다.

1. 동일 고정 조건으로 128회 연속 참조를 새로 학습.
2. 32회 정상 세대 저장.
3. 32회에서37회까지 학습 후 별도 writer가 배열 파일을 기록한 시점에서 강제 종료. 미완료 세대는 선택하지 않음.
4. 다시32회에서48회까지 학습 후 writer가 완전한 후보를 검증한 직후, 최종 경로에 게시하기 전에 강제 종료. 역시 선택하지 않음.
5. 다시32회에서64회까지 학습/저장 후 해당 저장본 archive의 한 바이트를 손상시킴.
6. 관리자가 손상된64회를 거절하고 자동으로32회를 선택. 96회까지 학습하고 writer가 게시한 직후 강제 종료.
7. 관리자는 유효한96회를 선택하여128회까지 학습, 최종 저장.
8. 참조와 파라미터4배열·모멘텀4배열·Torch RNG·샘플 순열, manifest 전체(손실/RNG/진행 등), 실제 최종 예측이 모두 정확히 일치함.

이 시험은 복구하는 데 드는 시간이 몇 배 빨라졌다는 성능 벤치마크가 아닙니다. 다시 수행한 업데이트를 비용으로 계산할 수 있지만 프로세스 시작 시간이 지배하는 작은 실험이므로 서비스 성능으로 확대하지 않습니다.

## 경계 검사

24개의 unittest 메서드는 빈 저장소, 정상 저장/선택, 동일 generation 중복 거절, 폴더명과 저장 step 불일치, 부분 파일, 손상 archive, NaN, JSON 중복키, bool schema alias, manifest/archive 크기 초과, 추가 파일, candidate/member/run/generation-directory 심볼릭 링크, 하드링크, 미완료 이름, 비표준 이름, entry 수 초과, traversal/외부 경로, 데이터 심볼릭 링크와 비삭제 dry-run을 다룹니다.

하나의 메서드 안에 여러 하위 입력이 있는 경우도 있으며 검사 수를 중복 합산하지 않습니다. 손상/부분 데이터의 이전 상태 fallback은 별도 실제 반복 실행으로 확인했습니다. 모든 저장본이 무효일 때는 NO_VALID_CHECKPOINT로 실패합니다.

## 명확한 한계

- 기존 단일 CPU, 동일 버전/타입/시드/데이터의 toy 실험이다. GPU·다중노드·운영환경 복구 증거가 아니다.
- 파일을 닫은 훅에서 종료했다. 임의 바이트 기록 중, 정전, 커널/파일시스템 장애, fsync 내구성을 검증하지 않았다.
- 동일 generation은 재저장도 거절한다. 동시 writer와 경쟁 조건을 다루는 lock/protocol은 없다.
- 경로 검사 후 파일이 동시에 악의적으로 바뀌는 경우를 막는 운영체제 수준의 sandbox가 아니다.
- 해시는 손상 탐지용이지 서명/작성자 인증이 아니다. 내용·해시·관련 메타데이터를 함께 위조한 공격은 보장하지 않는다.
- 기존 NPZ parser가 모든 trailing byte/모든 가능한 비정상 ZIP 표현을 거절한다는 주장을 하지 않는다. 고정 멤버/형태/타입·해시·크기·유한 값 등 정의된 검증을 수행한다.
- 임시/손상 세대는 자동 삭제하지 않는다. dry-run만 제공하며, 오래 쌓이면100개 entry 제한에서 멈춘다.
- 폴더명은 g+6자리 step만 인정하고 저장 step과 대조한다. 별도 alias를 동일 generation으로 선택하지 않는다. 동일 정식 이름의 덮어쓰기도 거절한다.
- 모델 예측력, 새 과학 발견, 사용자 독립 역량, 취업/채용 합격을 입증하지 않는다.

## 다음 확장보다 먼저

현재 범위가 독립 검토와 재현을 통과하면 작은 대표작으로 마감한다. 성능·분산·GPU로 자동 확대하거나 새 공개 배포를 시작하지 않는다. 기술을 설명할 때는 무엇을 검증했는지와 무엇을 검증하지 않았는지를 함께 제시한다.
