# 독립 감사

판정: **실험 구현·재현성 PASS, INT8 품질 게이트는 세 배치 모두 FAIL.** 감사 통과는 최적화 성공을 뜻하지 않습니다.

## 실제 확인
- 최종 소스에서 별도 Python 프로세스로 전체 학습·양자화·평가·벤치마크를 다시 실행했습니다. 가중치와 세 배치 예측 파일은 원본과 바이트 동일, 학습 loss·품질 지표도 정확히 일치했습니다. 시간은 달라지며 그대로 JSON에 보존했습니다.
- 71개 결과/원시 측정/분할 검사를 수행했습니다. 같은 검사의 반복을 포함하므로 고유 검사의 총수나 다른 검사와 합산하지 않습니다. NumPy로 합성 분할을 독립 생성하고 행 중복이 없음을 확인했습니다. 정확도·cross entropy·확률차·사전 gate를 다시 계산했습니다.
- FP32 NPZ를 고정 구조에 복원한 뒤 독립 양자화했습니다. 실제 dynamic quantized Linear 3개, INT8 weight/scale/zero/bias, 모든 배치 logits가 정확히 일치했습니다. pickle 파일을 로드하지 않았습니다.
- 원시 시간 CSV 120행에서 AB/BA 순서, 호출수, 블록평균 p50/p95, paired ratio와 표준편차를 재계산했습니다. 개별 요청 p95로 해석하지 않습니다.
- CLI 도움말·인수 누락·기존 출력·잘못된 인수·직접/조상/깨진 symlink 7경계 PASS. 기존 unit 7개도 재실행 PASS.
- 조상 symlink 거부와 calibration 결과 shape 명시 검사를 요청했고 수리 후 재검증했습니다.

## 해석
INT8 직렬화 크기 감소는 확인되지만, 최초 실행의 중앙값 추론 시간은 세 배치에서 모두 더 길었습니다. 최대 확률차가 사전 허용치 0.10을 넘으므로 세 조건의 품질 gate는 모두 실패입니다. 정확도의 작은 상승을 유의미한 개선으로 주장하지 않습니다.

## 범위
기존 Linux CPU와 Python 의존성을 재사용한 단일 호스트 실험입니다. 새 OS·실서비스·다른 모델·GPU·분산 검증이 아닙니다. 학습·양자화 시간은 추론 시간과 별도로 기록합니다. 파일 크기는 실행중 메모리나 실 배포 모델 크기를 뜻하지 않습니다. 외부 네트워크·설치·공개 게시 없이 수행했습니다.
